# Kotolňa Junior

Hrateľná webová hra na tréning kotolne — voda, plyn, vzduch, ťah, čerpadlo a bezpečnosť. Slovenčina, portrait, bez účtu.

Hra je v zložke [`trening-kotolne`](./trening-kotolne).

## Spustenie

```bash
cd trening-kotolne
npm install
npm run dev
```

Otvor `http://localhost:8080` (lepšie na mobile / úzkom okne).
