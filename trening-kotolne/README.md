# Tréning kotolne — Kotolňa Junior

Webová hra (React + TypeScript). Učí základy kotlového zariadenia: voda, horák, vzduch, dymák, obeh, tlak, alarmy.

## Ako spustiť

```bash
npm install
npm run dev
```

Port 8080. Ovládanie je na palec, najlepšie na výšku.

Postup sa ukladá do `localStorage` (level, meno, skóre). Žiadny účet, žiadny backend.

## Levely

1. Voda v kotle
2. Plyn a horák
3. Vzduch a spaľovanie
4. Dymák a ťah
5. Teplo do radiátorov
6. Tlak a poistka
7–8. Poruchy
9. Účinnosť
10. Záverečná skúška + certifikát
11–13. Bonusy

Keď sa zasekneš, stlač otáznik — poradí ďalší krok.
